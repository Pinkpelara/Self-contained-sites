What SizeReady does to a photo

Reduce photo file size. Keep the photo.

Everything becomes JPEG

PNG and WebP photos are changed to JPEG. JPEG is a small photo file that most forms take. See-through parts turn white. Moving photos become one still photo. Some fine detail is lost. That is how the file gets much smaller.

Width and height are top limits

Photos are never cut and never made bigger. A small photo stays small. SizeReady first lowers JPEG quality. Then it shrinks the photo in small steps, but only if you left the box checked.

Under the KB limit is not a pass

Schools, job sites, and travel forms also check file type, photo size, sharpness, shape, or file name. SizeReady only fixes file size. You must still read their rules and look at the saved file.

Compress image questions

What are the limits?

You can add up to 20 files. Each file can be up to 20 MB. The full batch can be up to 100 MB. One photo cannot be more than 24 megapixels. A megapixel means one million tiny dots of color. An example is a 6,000 by 4,000 photo. Big files need a lot of memory. Your browser may slow down.

Does KB mean 1,000 or 1,024 bytes?

Here 1 KB means 1,000 bytes. A 200 KB limit means 200,000 bytes or less. That also fits forms that mean 1,024 bytes. Those forms allow 204,800 bytes. Our file is smaller. So it still fits. If a rule says 250 KiB, enter 250.

Why did my photo come back smaller in pixels?

Width and height are top limits. They are not exact sizes. Photos are never cut. Photos are never made bigger. Your limits apply first. If lower quality is not enough, SizeReady can shrink the photo in small steps. This only happens if you left the box checked. This is a fast simple search. It does not promise the biggest photo that can fit.

Can I download everything at once?

No. Each photo has its own save link. There is no one click save for all photos. Save each file one by one.

Is an under-limit file sure to be accepted?

No. SizeReady only keeps the file under your KB limit. Sites can still say no. They may not like the file type, photo size, shape, sharpness, or file name. Read the rules on the form before you send it.

What about transparency or animation?

See-through parts turn solid white. Moving photos become one still JPEG photo. JPEG is a small photo file that most forms take. Look at the saved file before you send it.
