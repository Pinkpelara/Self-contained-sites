WiFi QR code how to

How to make a WiFi QR code that phones can scan

A WiFi QR code lets guests join with one scan. You type the name once, print the code, and tape it on the wall. These steps fit home, shop, and hall networks.

Open the free QR tool

Exact steps that work

Open the free QR tool on your phone or laptop. Pick WiFi login. Type the network name just as the router shows it. Caps, spaces, and dashes must match. HomeNet is not the same as homenet.

Pick the lock type. Most home routers use WPA. WPA2 and WPA3 both use the WPA pick in the tool. Pick WEP only for old gear that still asks for it. Pick no password for open guest nets with no key.

Type the key if there is one. Look for mix ups like zero and the letter O. Press Make QR code. You will see the square on screen. Test it now. Do not print yet.

Test the scan on your phone

Hold your phone camera up to the screen. On iPhone the Camera app shows a Join link. Tap it. On most Android phones the Camera app shows a Join button too. Move back a foot if it will not read. Use good light with no glare.

Ask a friend to test with WiFi off so the join is fresh. Then have them tap Forget so your key does not stay saved. If you host both iPhone and Android guests, test one of each. That one check saves a lot of trouble at party time. For cards that save a name and number in one scan, see our vCard QR code guide.

Print so it scans the first time

Print at least 1.5 inches wide. Two inches is best for a wall sign. Use dark ink on white paper. Keep a plain white edge round the code. Do not stretch it. Tape it flat where light hits it.

Write the network name in small print below as back up. If a scan fails, guests can still type it. Make a new code any time you change the key. A print never updates on its own. Your text stays on your device the whole time.

WiFi QR code questions

How do I make a WiFi QR code with the right name?

Type the exact network name with the same upper and lower case letters and spaces. Pick WPA, WEP, or no password to match your router. Press Make QR code, then test the scan on your phone before you print.

Which WiFi security type should I pick: WPA, WEP, or no password?

Pick WPA for most home routers made after 2006. Pick WEP only for old gear that still asks for it. Pick no password for open guest networks with no key.

Why does my WiFi QR code not join on some phones?

Most misses come from a wrong name, a wrong password, or a hidden network. Check the spelling, test on two phones, and print the code at least 1.5 inches wide in dark ink on white paper.
